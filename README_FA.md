# راه‌اندازی سایت GG_LAND

این پروژه یک سایت CS2 با تم مشکی/طلایی، نمایش VIP با قیمت ۷۵,۰۰۰ تومان و پنل خصوصی مدیریت لینک‌هاست.

## امکانات
- بازدیدکننده فقط لینک‌ها را می‌بیند.
- مدیر با رمز عبور وارد پنل می‌شود و لینک اضافه/حذف می‌کند.
- رمز مدیر داخل کد سایت قرار ندارد؛ از متغیر محیطی `ADMIN_PASSWORD` خوانده می‌شود.
- نشست مدیریت با کوکی HttpOnly و امضای سرور ساخته می‌شود.

## اجرا روی کامپیوتر
نیازمند Node.js نسخه ۲۰ یا بالاتر:
1. ترمینال را در پوشه پروژه باز کن.
2. متغیرهای محیطی را تنظیم کن:
   - `ADMIN_PASSWORD` = یک رمز قوی و اختصاصی
   - `SESSION_SECRET` = یک رشته تصادفی طولانی و محرمانه
3. اجرا:
   - `npm install`
   - `npm start`
4. مرورگر را روی `http://localhost:3000` باز کن.

## انتشار آنلاین
این پروژه را می‌توان روی میزبان Node.js مثل Render یا سرویس مشابه منتشر کرد:
- Build command: `npm install`
- Start command: `npm start`
- Environment: `ADMIN_PASSWORD`, `SESSION_SECRET`, `NODE_ENV=production`
- برای ماندگاری لینک‌ها بعد از راه‌اندازی مجدد، دیسک دائمی متصل کن و `DATA_FILE` را روی مسیر داخل آن قرار بده؛ مثلاً `/var/data/links.json`.
- حتماً HTTPS را فعال نگه دار.

## نکته مهم
این فایل‌ها به‌تنهایی سایت را روی اینترنت منتشر نمی‌کنند. برای گرفتن لینک عمومی باید در سرویس میزبانی حساب بسازی و پروژه را آنجا Deploy کنی. رمز مدیریت را برای هیچ‌کس نفرست. پرداخت VIP هنوز به درگاه پرداخت و فرایند تحویل واقعی رنک سرور متصل نشده است.
